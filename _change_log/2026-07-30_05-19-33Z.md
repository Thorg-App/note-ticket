Strangler-fig step T3. `TS_COMMANDS` is now `help --help -h ls list ready blocked closed query`; each command was flipped separately with the BDD suite green in between. Bash `./ticket` remained the contract, verified differentially rather than by inspection.

Suites at completion: typecheck 0, 251 unit tests, 208 BDD scenarios / 1368 steps, parity 69 graph scenarios with 7 pinned divergence checks — all zero failures.

Bugs found and fixed along the way:
- `query` emitted invalid JSON for control characters; bash's own `query .id` died inside jq on `tk create $'tab\there'`.
- Broken-pipe deaths surfaced as exit 1 because `spawnSync` reports both `signal: SIGPIPE` and `error: EPIPE` and the error was read first; now 141, matching bash at both ends of the output-size range.
- `closed` sorted symlinked tickets by the target's mtime; GNU `ls -t` lstats its operands, so it now uses the link's own mtime.
- The parity harness itself invoked `./ticket`, which execs the TS bundle for ported commands — the differential checks were about to compare TS against TS. Its bash side now has `TS_COMMANDS` emptied, and `make parity` depends on `make build` so a stale bundle cannot pass.

Declared divergences where TS is the more correct behavior (each in the parity whitelist, the migration doc, and a pinning test): `|` in a title (bash truncates on its `prio|id|status|title` sort key), `--limit=` plain counts only (bash inherited `head -n` syntax), `--limit=0` deterministic 0 (bash's code was racy — measured 35x141 / 25x0 over 60 identical runs), bad `--limit=` reported on an empty dir, control-character escaping, a missing `jq` reporting 127 with an actionable message, and the mid-size broken-pipe band (bash flips 0 to 141 at awk's 4 KB buffer, TS at the 64 KB pipe buffer).

Guards were mutation-tested rather than assumed. Three early mutations survived and those holes were closed (no fixture exceeded the 100-file scan cap, none had `status: done`); two tests were found vacuous and fixed, one of them the implementer's own nanosecond-mtime test whose fixture name let a path tie-break supply the expected answer.
