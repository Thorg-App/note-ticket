The published docs advertised `brew tap wedow/tools && brew install ticket-core` and
`yay -S ticket-core`. Neither exists for this fork -- the tap belongs to upstream
wedow/ticket. Removed the docs AND the automation behind them (publish-homebrew.sh,
publish-aur.sh, pkg/aur/PKGBUILD, the release-workflow steps), since CI publishing to a tap
we do not own was the same falsehood.

Distribution is now: npm (`note-ticket`) or a symlink into a git checkout. The CLI installs
under one name, `ticket`; the `tk` bin alias is gone (BREAKING for scripts calling `tk` from
an npm install). ORIGINAL_README.md deleted, its agent-setup snippet moved to docs/cli.md.

KEPT: the wedow/ticket MIT attribution (THIRD_PARTY_LICENSES.md + README license line) --
required by the license.

Green: make typecheck, make test (261 scenarios), make package-smoke.
